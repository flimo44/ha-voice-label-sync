# HA Voice Label Sync v1.1.0-beta.1

**Préversion de la prochaine évolution de HVLS.** Elle vise principalement les installations neuves, la migration d'un ancien fichier d'entités Google Assistant et la réparation d'une configuration perdue ou incohérente.

## Nouveautés

- **Installation guidée** : sélectionner les entités dans Home Assistant ou reprendre un fichier YAML existant sans effacer ni écraser automatiquement la production.
- **Reprise d'un YAML historique** : analyser les entités disponibles, absentes ou non éligibles, conserver les entités déjà étiquetées dans HA et présenter précisément les différences dans le Preview.
- **Sauvegarde préalable et propriété vérifiée** : récupération contrôlée d'un fichier appartenant à une ancienne installation HVLS.
- **Réparation sans réinstaller** : reconstruire un YAML de production disparu depuis les étiquettes HA après examen et validation.
- **Restauration plus robuste** : préparer et appliquer une sauvegarde après validation, même si le YAML de production manque, avec examen des entités obsolètes et des étiquettes.
- **Interface plus claire** : les modifications d'étiquette en attente ne sont pas écrasées par une autre génération ; « Choisir mes entités dans HA » ouvre directement le gestionnaire d'entités.

## Garanties

- Aucun ajout ou retrait d'étiquette et aucune mise à jour du YAML sans Preview contrôlé puis confirmation.
- Les fichiers d'une autre installation, les chemins non sûrs, les changements intervenus depuis le Preview et les opérations interrompues restent protégés.
- Les sauvegardes existantes sont préservées ; une sauvegarde de sécurité est créée avant de remplacer un YAML existant.

## Validation

Les vérifications Python/JavaScript, HACS, Hassfest, packaging et Home Assistant Core accompagnent cette bêta. Des scénarios de reprise d'un ancien fichier (40 vers 28 entités), de création initiale (28 entités), de persistance après redémarrage et de récupération d'un fichier manquant ont été éprouvés sur une VM de test. La compatibilité de toutes les installations reste à confirmer grâce aux retours bêta.

## Avant installation

**Préversion** : faire une sauvegarde/snapshot de Home Assistant et conserver une copie du YAML existant. Installer la préversion publiée dans HACS (ou son fichier `ha_voice_label_sync.zip`), redémarrer HA et examiner chaque Preview avant de valider.

Cette version **n'automatise pas Google Cloud, le DNS/HTTPS ni l'association Google Home**. Elle utilise le moteur Python `ha-voice-label-sync==0.3.6`, déjà diffusé sur PyPI : aucun nouveau package PyPI n'est publié ici.

Pour les changements détaillés : [CHANGELOG.md](https://github.com/flimo44/ha-voice-label-sync/blob/feat/reinstall-recovery-via-preview/CHANGELOG.md).
